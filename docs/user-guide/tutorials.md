# Pixal3D tutorials

The homepage links to four practical guides:

- **Local installation** (`/how-to-install-locally`): base environment, dependencies, model sources, and a first GLB export.
- **GGUF** (`/gguf`): community quantized models, required companion files, and their ComfyUI loader.
- **Low VRAM** (`/low-vram`): official memory-saving options and the limits of reported RTX 2070 compatibility.
- **ComfyUI** (`/comfyui`): official native nodes, model folders, a single-image workflow, and troubleshooting, with the older community package documented separately.

Use the language switch in the header for Chinese versions. Each guide includes links to original documentation, reported performance evidence, and source screenshots. Published community measurements describe a specific machine and workflow; they do not guarantee the same result on your computer. Missing data is marked explicitly.

The embedded workspace has a Pixal3D title bar and Hugging Face source link. It starts loading near the viewport and stays mounted when you scroll away. If it does not respond, use the help control to reload it or open it in another tab. Reloading resets the embedded page, so keep it open while a job is running.

Reading guides is public. The homepage workspace retains its existing sign-in overlay. Model generation and downloads inside the current HF iframe cannot yet be counted by this site; that requires the embedded app to provide separate events.
