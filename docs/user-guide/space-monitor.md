# 工作台自动换源

Pixal3D、TRELLIS.2 和 Hunyuan3D 2.1 的内嵌工作台共用后台巡检服务。启用线上任务后，后台约每三天检查一次，不需要保持电脑或 Codex 开启。

原 Space 连续两次检查确认故障时，后台会寻找同模型、同版本的备用 Space，并检查源码身份、页面、可嵌入性以及输入和导出控件。排队、休眠、登录要求和额度不足不会直接触发换源。没有找到合格替代时，会保留当前地址并记录原因。

换源在下次打开工作台或点击“重试加载”时生效。当前已经打开的工作区会保留，避免中断正在进行的操作。三个模型分别维护地址，一个模型换源不会影响另外两个。

检查不会提交图片或执行生成任务，因此不消耗生成额度。它能发现页面下线、启动报错和嵌入限制，但不能保证当时有可用 GPU，也不能代替一次完整生成测试。更换 Space 也不能解除用户的 Hugging Face 配额限制。

管理员可查看上次检查、下次检查、当前和上一个 Space、最近20条记录；需要回退时，后台会先重新检查上一个 Space。部署和管理接口见[实现文档](../implementation/space-monitor.md)。
